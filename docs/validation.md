# 0.1.0 验证记录

日期：2026-11-03。

- 本机 macOS ARM64：Node 26.8.1、Docker 29.7.2、Compose 5.4.0。
- 自动化单元测试覆盖环境隔离、重复初始化、命令帮助、参数校验、批量模块维护、日志事件与遮盖、镜像计划与离线文件。
- npm 包使用 files 白名单，仅包含管理程序、文档和许可；不包含 Odoo 服务端源码、真实配置、数据库或附件。
- 发布前需验收 npm pack 安装后的命令，以及独立临时项目的启动、批量模块安装升级、带附件 ZIP 备份恢复、卷保留和显式删除。
- Windows/macOS/Linux Node 24 的 CI 配置不等于各平台真实 Docker 验收；Windows 原生 Docker 与 Linux Docker 未在本机实测。

详细本机验收结果在实际执行后补充。
